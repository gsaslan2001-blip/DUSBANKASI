DUSBANKASI Project Comprehensive Report
1. APP PURPOSE
DUSBANKASI (Turkish Dental Exam Question Bank) is an advanced dental exam preparation platform built with React. It's specifically designed for Turkish dentistry students preparing for the DUS (Diş Hekimliği Ulusal Sınavı) national exam. The app features:

Question Bank Management: Import, organize, and manage dental exam questions by lesson/unit
Adaptive Learning: Statistics-based priority queue (weakness + new-exploration signals) for optimized question sequencing — spaced repetition is BANNED (handled externally in Anki)
Multiple Study Modes: Quiz mode (unit-based), Exam mode (mixed questions), DUS Simulation (timed national exam simulator)
Cloud Sync: Supabase backend for data persistence and cross-device synchronization
Comprehensive Analytics: 25+ data visualizations showing study patterns, accuracy metrics, and progress tracking
Daily Exam System: Personalized daily practice exams with progress tracking
Smart Study: ML-driven intelligent question selection based on performance metrics

5. KEY UI PATTERNS & DATA FLOWS
State Management:

React Hooks (useState, useContext) for local component state
Zustand for global app state (auth, theme, sync status)
localStorage for offline stats and resumable sessions
Supabase Realtime for cross-device synchronization
Data Flow Architecture:

Questions (Supabase DB)
    ↓
useQuestions Hook (fetches, caches, updates)
    ↓
App State (examQuestions, unitQuestions, quizStats)
    ↓
QuizView / StatisticsView / SimulationResultView
    ↓
Stats Library (adaptive.ts, stats.ts)
    ↓
D3 Charts + React Components
    ↓
Responsive UI (Tailwind + Framer Motion)
Navigation State Machine:

select-lesson (home)
  ├─ select-unit
  │  └─ quiz (unit-based)
  ├─ select-deneme → select-deneme-amount → quiz (exam mode)
  ├─ select-favorites → select-deneme-amount → quiz
  ├─ analytics (StatisticsView with 25 charts)
  ├─ error-analysis (ErrorAnalyticsView)
  ├─ simulation-setup → quiz (timed) → simulation-result
  ├─ daily-plan
  ├─ smart-study (AI-selected questions)
  ├─ result (post-quiz stats)
  ├─ import (CSV/JSON import)
  └─ source-books
Resume & Persistence:

Resumable sessions saved in localStorage with structure: { questions, answers, currentIndex, mode, dailyExamId }
Cloud sync via SyncManager batches and pushes stats to Supabase
Real-time stat merging across devices
Per-question statistics stored with attempts, corrects, wrongChoices (no scheduling state)
Animation Patterns:

Framer Motion: Page transitions (slide-up, fade), button hovers, card reveals
React Spring: Smooth number animations, spring easing
CSS animations: Spinner loops, pulse effects (defined in App.css)
Canvas Confetti: Celebration animation on exam completion
Theming System:

3 themes: dark, oled, light (stored in /theme directory)
Tailwind utility-based (gradients, shadows, colors)
Real-time class toggling on document.documentElement
Color system: Indigo (primary), Rose/Amber/Emerald/Cyan (semantic accents)

7. NOTABLE UI/DATA ARCHITECTURE DECISIONS
Adaptive Question Pool Building (adaptive.ts): Statistics-based weakness scoring (accuracy + wrong-choice history) — no forgetting-curve or scheduling math
Stats Versioning: statsVersion React state forces component re-renders after cloud sync to ensure fresh data visualization
ResizeObserver Pattern: All D3 charts use ResizeObserver for responsive viewport-aware rendering
Session Resumption: Differentiates between quiz/exam modes; daily exams get special tracking
PDF Export: Custom HTML + CSS (not PDF library) printed through browser to preserve formatting
Real-time Notifications: Sonner toasts for sync status, Supabase realtime for cross-device updates
Offline-First: localStorage primary, cloud as backup; SyncManager handles batching during offline periods
