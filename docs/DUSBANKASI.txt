DUSBANKASI Project — Comprehensive Technical Overview
Project Name: DUSBANKASI (Diş Hekimliği Uzmanlık Sınavı Soru Bankası)
Purpose: AI-driven adaptive question bank platform for Turkish dentistry exam (DUS) preparation
Live URL: https://odusbircanavari.vercel.app

Python 3.12 with asyncio, aiohttp

Visualization:

3. CORE FEATURES & MODES
Study Modes (6 Types):

Unit Study — All questions in a unit (unseen prioritized)
Exam Mode (Deneme) — Mixed subjects with greedy interleaving
DUS Simulation — Real exam format, timed, 50–200 questions
Weak Topic Recovery — High-error units prioritized
Favorites Panel — User-starred questions
Daily Exam (Atlas-driven) — AI recommends today's topics; 80% new + 20% weak/medium/easy
Adaptive Learning Engine:

2-signal priority queue: weakness score (70%) + new-exploration (30%)
Greedy interleaving: consecutive Qs from different lessons (discriminative learning)
Resumable sessions: saved to localStorage + cloud (active_sessions table)
No FSRS scheduling—purely statistics-based (accuracy, question count, activity)
Quality & Analytics:

Error pattern tracking (wrong choice histograms per unit)
Cross-device sync (same session on phone picks up where desktop left off)
Exam score projections (10,000 Q target; daily pace required)
30 D3 charts: time-series activity, consistency box plots, heatmaps, Sankey flows, etc.
4. DATABASE SCHEMA (Key Tables)
Table	Purpose
questions	Lesson/unit/stem/options/correct answer/explanation + embeddings (stem_embedding, explanation_embedding, legacy embedding) + quality_flag
question_stats	Per-user: attempts, corrects, wrong_choices array, difficulty, last_seen
user_data	User-level JSON blobs (activity, streak, settings)
active_sessions	Cloud resume: user_id + questions array + answers + current index
daily_exams	Scheduled exams: user + questions (UUID array) + completion status
exam_answers	Per-exam: question + selected choice + time spent
reference_sources	PDF metadata for RAG context (lesson/unit/file path)
5. UI/UX PATTERNS
State Machine: App.tsx navigates 17 states (select-lesson → select-unit → quiz → result → analytics, etc.)
Responsive Virtualization: @tanstack/react-virtual for 10,000+ question lists
Theming: Tailwind utility classes + document.documentElement class toggle (real-time)
Animations: Framer Motion page transitions (slide-up, fade), React Spring number easing, canvas confetti on completion
Offline-First: localStorage primary; SyncManager batches/pushes stats during connectivity
Session Recovery: Persists question pool, answers, timer, and daily exam ID; restores seamlessly
